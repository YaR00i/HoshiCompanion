# Hoshi Companion 3D · 0.6

Локальный мини-компаньон для Windows на Godot + VRM 1.0.

Хоши умеет моргать, смотреть на курсор, гулять по нижнему краю экрана, садиться
на пол и на края, махать, дремать и использовать небольшие сидячие занятия:
болтать ногами, откидываться на ладони и с любопытством смотреть вниз.

## Места отдыха

В примерочной и меню есть «Мой уютный уголок» — компактное собственное окно.
Настройка «Где отдыхать»:
- **Только вручную** — никакого автоматического выбора опоры;
- **Свой уголок** — самостоятельный отдых проходит в её собственном окошке;
- **Окна → уголок** — Хоши один раз ищет безопасный край обычного окна на текущем
  мониторе, а если подходящего места нет, открывает свой уголок.

Это редкое действие с длинными паузами, а не постоянное сканирование. Ручной выбор
окна под курсором с четырёхсекундным отсчётом из 0.5 сохранён отдельно.

Настройка «На краю» позволяет оставить автоматический выбор позы либо вручную
выбрать спокойную посадку, болтание ногами, откидывание назад или взгляд вниз.

## Модель

Публичный репозиторий содержит только код. Локальный VRM положи в:

```text
assets/Hoshi_v1.vrm
```

`assets/*.vrm` исключён через .gitignore. MIT относится к исходному коду, а не к
добавленной модели. Подробнее: MODEL_NOTICE.txt.

## Запуск

Рекомендуемый движок: Godot 4.7.2; baseline — Godot 4.5.1+.
PREVIEW_WINDOWS.bat — примерочная, START_WINDOWS.bat — рабочий стол,
SHELF_DEMO_WINDOWS.bat — тестовая полочка, OPEN_EDITOR.bat — редактор.

Для функций внешних окон нужен локальный Python 3. Путь можно хранить в
`python_path.txt`; файл локальный и не коммитится.

## Приватность

Ручной режим читает геометрию/состояние одного выбранного HWND. Автоматический режим
включается отдельно и делает только короткий ограниченный перебор top-level окон,
чтобы найти геометрически пригодный край. Заголовки, текст, пиксели экрана, вкладки,
микрофон, камера и сеть не читаются. Hook-служб и автозапуска нет.

Подробнее о поведении и ограничениях: `docs/LIVING_06.md`.
