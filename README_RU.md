# Hoshi Companion 3D · 0.7

Локальный мини-компаньон для Windows на Godot + VRM 1.0.

Хоши умеет моргать, смотреть на курсор, гулять по нижнему краю экрана, садиться
на пол и на края окон, махать, дремать и использовать небольшие сидячие занятия:
болтать ногами, откидываться на ладони и с любопытством смотреть вниз.

## Что нового в 0.7

Появился отдельный слой контекстных движений рабочего стола:
- при переносе мышкой Хоши висит мягче, как маленький «котёнок на весу»;
- если отпустить её вне опоры, она падает вниз и приземляется, а не телепортируется;
- на окно/полочку она теперь запрыгивает дугой;
- при запуске рабочего режима появляется процедурная магическая дверь со звёздным
  небом, из которой Хоши выходит;
- при обычном закрытии она сначала возвращается вниз, затем уходит обратно в дверь,
  и только после этого процесс завершается;
- на активной опоре можно выбрать «Пройтись по опоре» — маршрут идёт в координатах
  самого окна, поэтому при перемещении опоры Хоши остаётся привязана к ней;
- на достаточно высоком внешнем окне доступны «Опора у левого края» и
  «Опора у правого края», после чего можно выбрать «Сесть обратно».

Уютный уголок теперь после показа поднимает окно Хоши выше себя, чтобы его панель
не перекрывала ноги персонажа.

## Места отдыха

Настройка «Где отдыхать» из 0.6 сохранена:
- **Только вручную** — никакого автоматического выбора опоры;
- **Свой уголок** — самостоятельный отдых проходит в её собственном окошке;
- **Окна → уголок** — один короткий geometry-only поиск безопасного края обычного
  окна на текущем мониторе, иначе открывается свой уголок.

Это редкое действие с длинными паузами, а не постоянное сканирование. Ручной
четырёхсекундный выбор окна сохранён отдельно.

## Модель

Публичный репозиторий содержит только код. Локальный VRM положи в:

```text
assets/Hoshi_v1.vrm
```

`assets/*.vrm` исключён через .gitignore. MIT относится к исходному коду, а не к
добавленной модели. Подробнее: MODEL_NOTICE.txt.

## Запуск и проверка

Рекомендуемый движок: Godot 4.7.2; baseline — Godot 4.5.1+.
`PREVIEW_WINDOWS.bat` — примерочная, `START_WINDOWS.bat` — рабочий стол,
`SHELF_DEMO_WINDOWS.bat` — тестовая полочка, `OPEN_EDITOR.bat` — редактор.

Памятка для ручной приёмки 0.7: `docs/ACCEPTANCE_07_RU.md`.

## Приватность

Ручной режим читает геометрию/состояние одного выбранного HWND. Автоматический режим
включается отдельно и делает только короткий ограниченный перебор top-level окон.
Заголовки, текст, пиксели экрана, вкладки, микрофон, камера и сеть не читаются.
Hook-служб и автозапуска нет.
