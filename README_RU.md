# Hoshi Companion 3D · 0.5.1

Локальный мини-компаньон для Windows на Godot + VRM 1.0.

Текущая версия умеет:
- моргать, смотреть на курсор и показывать выражения лица;
- гулять по нижнему краю рабочей области;
- садиться на пол и дремать сидя;
- сидеть на собственном тестовом окне-полочке;
- вручную садиться на верхний край выбранного обычного окна;
- сохранять посадку при перемещении/изменении размера опоры;
- махать, реагировать на поглаживание и использовать небольшие действия на краю:
  болтать ногами, откидываться на ладони и смотреть вниз.

## Важно: модель не входит в репозиторий

Публичный репозиторий содержит только код. Локальный VRM нужно положить в:

```text
assets/Hoshi_v1.vrm
```

`assets/*.vrm` исключён через .gitignore. Лицензия MIT относится к исходному коду,
а не к добавленной пользователем модели. Подробнее: MODEL_NOTICE.txt.

## Запуск

Рекомендуемый движок для разработки: Godot 4.7.2; проект рассчитан на Godot 4.5.1+.

Windows:
- PREVIEW_WINDOWS.bat — примерочная;
- START_WINDOWS.bat — прозрачный компаньон;
- SHELF_DEMO_WINDOWS.bat — собственная полочка;
- OPEN_EDITOR.bat — открыть проект в Godot;
- DEV.cmd — автоматические проверки.

Для ручной посадки на чужое окно используется локальный Python 3.
Можно положить путь в `python_path.txt`; файл локальный и не коммитится.

## Приватность

Обычный запуск не анализирует другие приложения. Команда выбора окна запускает
короткоживущий помощник только по явному действию пользователя. Он получает геометрию
и служебное состояние одного выбранного HWND, не читает заголовки, содержимое страницы,
пиксели экрана, микрофон, камеру или сеть. При отсоединении помощник завершается.

Полноэкранные/развёрнутые и некоторые системные окна не используются как опора.
Если опора закрыта или свёрнута, компаньон возвращается вниз.

## Проверки

- `python tools/dev.py check` — основной набор;
- `python tools/dev.py shelf_windows` — жизненный цикл собственной полочки;
- `python tools/dev.py external_windows` — изолированное тестовое окно;
- `python tools/dev.py edge_views` — рендеры сидячих действий.

Полный regression-набор сейчас калиброван под локальную Hoshi-модель; произвольному
VRM может потребоваться настройка походки и поз. Архитектура и ограничения — в `docs/`.
