# Промпт для Codex: подключить Codex к пульту Хоши так же, как Claude

Скопируй текст ниже в Codex (в этой папке проекта).

---

Ты работаешь в проекте Hoshi Companion (Godot 4.7, Windows), ветка `chatgpt/hoshi-0.7`.
Сначала прочитай `AGENTS.md`, `CLAUDE.md` (как работать с пользователем: по-русски, на «ты»,
просто, маленькими шагами, **никаких commit/push/веток без его явного разрешения**) и
`docs/REMOTE_RU.md` — разделы «Claude Code на пульте», «Ответить Claude с телефона»,
«Разрешения и вопросы», «История бесед», «Облачко над Хоши».

## Задача

Подключить **Codex** к пульту Хоши и к облачкам над Хоши **точно так же, как уже подключён
Claude Code**, с тем же интерфейсом — пользователь хочет, чтобы всё выглядело одинаково:

1. **Облачко над Хоши** для Codex (уже заложено: `scripts/assistant_clouds.gd` рисует `codex`
   мятным «</>»): работает — «дышит», закончил — ✓, ждёт — ?. Несколько помощников —
   облачка столбиком.
2. **Карточка «Codex» на главной пульта** (иконка ⌨️ уже есть в `APP_ICONS` в
   `remote/remote.html`), как карточка Claude: папка проекта, статус, текст последнего ответа,
   картинки/ссылки из ответа, «💬 Беседа», «🗂 Все сессии», быстрые кнопки
   «👋 Ты тут? · ▶ Продолжай · ✓ Ок · 💾 Коммить», поле «Ответить…».
3. **Ответ с телефона** в сессию Codex.
4. **История бесед Codex** (текущая беседа и список сессий), только тексты сообщений.

## Как устроено у Claude (повтори это для Codex, не ломая Claude)

- `tools/claude_hook.py` — хук Claude Code: «записки» на `http://127.0.0.1:18772/assistant`
  (события SessionStart, UserPromptSubmit, Notification, Stop, StopFailure, SessionEnd);
  `--wait` — «ждун» ответа с телефона; `--ask` — разрешения и вопросы; маленький журнал
  диагностики без текстов.
- `scripts/assistant_watch.gd` — приёмник записок (только 127.0.0.1), сессии в памяти,
  карточка — встроенный аддон `claude` (peer -2) в `scripts/app_adapters.gd`, облачка
  (`clouds()`), история (`request_history`).
- `scripts/remote_bus.gd` — маршрут команд `app:claude:*`, op `history` только запросившему телефону.
- `tools/claude_history.py` — чтение журналов `~/.claude/projects/*/<id>.jsonl`.
- Тесты: `tests/test_assistants.gd`; всё проверяется `python tools/dev.py check` (failures=0).

## Что известно про Codex

- У Codex есть хуки (документация: https://learn.chatgpt.com/docs/hooks): события
  `SessionStart`, `UserPromptSubmit`, `PermissionRequest`, `Stop` (в JSON есть
  `last_assistant_message`), `SessionEnd` и др.; во входном JSON есть `session_id`,
  `transcript_path`, `cwd`. Хуки — в `~/.codex/hooks.json` или `[hooks]` в
  `~/.codex/config.toml`; на Windows — поле `commandWindows`; есть `"async": true`.
- Ответ с телефона: у Codex нет «asyncRewake», зато хук `Stop` может вернуть
  `{"decision": "block", "reason": "<текст>"}` — Codex продолжит с этим сообщением. Пока
  хук ждёт ответа с телефона, Codex выглядит занятым — ждать ограниченное время
  (предложи 5 минут; спроси пользователя), потом отпускать.
- **Не трогай существующий `notify`** в `~/.codex/config.toml` (его использует
  «управление компьютером» Codex). Хуки — отдельно, в `hooks.json`.
- Сейчас в Codex `approval_policy = "never"` — разрешения не спрашиваются; «Разрешить /
  Запретить» для Codex можно сделать тем же путём (`PermissionRequest`), но это не главное.
- Журналы бесед Codex: проверь, где лежат (`transcript_path` из хука; обычно
  `~/.codex/sessions/.../rollout-*.jsonl`) и в каком формате; бери только тексты
  сообщений пользователя и ответов, без вызовов инструментов, их результатов и «мыслей».

## Как делать (по шагам, после каждого — `python tools/dev.py check`)

1. Аудит: прочитай код выше, проверь формат хуков и журналов Codex на этом ПК. Покажи
   пользователю план и спроси решения (ниже). Ничего не меняй до его ответа.
2. Обобщи `assistant_watch.gd` на несколько помощников (`app`: claude / codex): сессии,
   карточка на каждого (codex — свой peer, например -3), облачка по приложениям. Claude
   должен работать как раньше — все его тесты зелёные.
3. Хук для Codex (например, `tools/codex_hook.py` или общий хук с `--app codex`), записки
   с `app: "codex"`, те же ограничения приватности: имя папки, а не путь; тексты — только
   ответы; журнал диагностики без текстов.
4. Ответ с телефона через `Stop` → `decision: block` с ограничением ожидания.
5. История Codex (помощник, как `tools/claude_history.py`, или общий).
6. Страница пульта: карточка Codex = тот же код, что у Claude (без копипаста — общий
   рендер для «помощников»).
7. Тесты в `tests/test_assistants.gd` (для Codex — как для Claude), документация в
   `docs/REMOTE_RU.md`, правила в `AGENTS.md`.
8. Установку хуков в `~/.codex/hooks.json` сделай только после явного «да» пользователя.

## Решения, которые нужно спросить у пользователя (на ПК, не с телефона)

- Приватность Codex как у Claude: статус, имя папки, текст последнего ответа, история
  бесед (тексты сообщений) — на привязанный телефон по домашнему Wi-Fi без шифрования?
- Писать Codex с телефона: сколько ждать ответа в хуке `Stop` (Codex всё это время «занят»)?
- Ставить хуки глобально (`~/.codex/hooks.json`) или только для этого проекта?

## Правила проекта, которые важно не нарушить

- VRM-модель, `.workspace/`, `godot_path.txt`, `python_path.txt` — никогда в Git.
- Внешние окна: только геометрия и имя программы; заголовки/тексты окон не читать.
- Телефон нажимает только готовые команды; текст для ИИ-помощника — осознанное
  исключение (как у Claude), решение пользователя.
- Команды приложениям — только по нажатию человека.
- Коммиты — только с явного разрешения пользователя.
