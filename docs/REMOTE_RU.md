# Пульт Хоши с телефона и аддоны приложений

Сентябрь 2026. Первый шаг «шина команд + пульт». Работает только в домашней
сети (Wi-Fi), из интернета недоступен.

## Как включить

1. Меню Хоши (ПКМ → «Все действия и настройки») → **Пульт с телефона → Пульт включён**.
   Откроется окно с адресом вида `http://192.168.1.23:18770/` и кодом из 6 цифр.
2. Если Windows спросит про доступ Godot к сети — разреши для **частной** сети.
3. На телефоне (в той же Wi-Fi) открой адрес в браузере и введи код.
   Код одноразовый: следующему телефону Хоши покажет новый.
4. Телефон запоминает привязку; при следующем открытии код не нужен.
   В браузере телефона можно «Добавить на главный экран» — будет как приложение.

Пульт включается снова сам при следующем запуске Хоши, если был включён.
«Забыть все телефоны» — отвязать все телефоны сразу.

## Что есть на пульте

- строка состояния: что Хоши сейчас делает;
- разделы команд: общение, движение, места, на окне, сценки, настроение,
  занятие сидя, ритм дня, где отдыхать, самостоятельность. Выбранные режимы
  подсвечены;
- **разделы подключённых приложений** (например, YouTube): что играет,
  прогресс, кнопки приложения. Раздел появляется, когда аддон подключён, и
  исчезает, когда он отключился.

## Как это устроено

```
телефон ──(Wi-Fi, код)──► remote_bus.gd ──► app.run_command(имя) ──► исполнитель команд
                                   │
расширение Chrome ──(этот ПК)──────┘──► app_adapters.gd ──► кнопки «YouTube» на пульте
```

- `scripts/remote_bus.gd` — страница (порт 18770) и WebSocket (порт 18771).
- Телефон может запускать только команды с источником `remote` в
  `hoshi_commands.gd` (это всегда подмножество команд меню) и команды
  подключённых аддонов. «Закрыть Хоши», примерочная, диагностика, выбор окна
  курсором с телефона недоступны.
- Команды Хоши с телефона идут через тот же исполнитель, что и кнопки меню.
- `remote/remote.html` — страница пульта: одна HTML-страница без внешних
  библиотек и интернета.

## Безопасность

- Выключено по умолчанию.
- Принимаются соединения только из локальной сети (`192.168.*`, `10.*`,
  `172.16–31.*`, link-local, `127.0.0.1`); адреса из интернета отклоняются.
- Без привязки по коду телефон ничего не может. 5 неверных кодов — новый код.
- Ключи привязки хранятся в настройках Хоши на ПК.
- Ограничение частоты нажатий и размера сообщений.
- Аддоны подключаются **только с этого же ПК** (`127.0.0.1`).

## Протокол для аддонов (расширение Chrome, аддон Blender)

WebSocket `ws://127.0.0.1:18771/hoshi-adapter-v1`, JSON-сообщения.

Аддон → Хоши:

```json
{"op": "adapter", "id": "youtube", "title": "YouTube",
 "commands": [
   {"name": "toggle", "title": "Пауза", "icon": "⏸"},
   {"name": "seek", "title": "+10 с", "icon": "⏩", "args": {"seconds": 10}}
 ],
 "state": {"title": "Название видео", "subtitle": "Канал", "time": 42, "duration": 3600,
           "playing": true, "active": ["like"]}}
{"op": "adapter_state", "state": {...}}
{"op": "event", "id": "youtube", "event": "liked"}
```

Хоши → аддон, когда на пульте нажали кнопку:

```json
{"op": "run", "command": "seek", "args": {"seconds": 10}}
```

- `id` и `name`: латиница, цифры, `_` (до 24 символов). На пульте и в шине
  команда называется `app:<id>:<name>`, например `app:youtube:seek`.
- `state.title`, `state.subtitle`, `state.time`, `state.duration` пульт
  показывает как «что играет»; `state.active` — какие кнопки подсветить.
- События (`liked`, `ended`, …) Хоши может сопровождать реакцией.
- Команды аддонов выполняются **только по нажатию человека**; сама Хоши их не
  запускает.

## Проверка

- `python tools/dev.py remote` — страница, привязка, запреты, маршрут команды
  до аддона-заглушки и обратно (31 проверка, без сети наружу).
- На Windows: включить пульт, открыть адрес с телефона, привязать, нажать
  «Помахать» — Хоши машет. Выключить Wi-Fi на телефоне — пульт пишет
  «Хоши не на связи», при возвращении подключается сам.
