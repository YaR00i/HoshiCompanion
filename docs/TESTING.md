# Проверки 0.2

## Выполнено при сборке, без Godot

1. `python tests/validate_asset.py`: исходный VRM, SHA-256, ссылки ресурсов, структура.
2. `python tests/validate_hotfix.py`: прежние контракты исправленной привязки мимики.
3. `python tests/offline/check_syntax.py`: 12 GD-файлов разобраны Lark-грамматикой,
   адаптированной из gdtoolkit. Это не type checker и не компиляция Godot.
4. `python tests/offline/check_motion.py`: 212 проверок. Исполняется ограниченная
   механическая Python-адаптация чистых locomotion/director, не GDScript-движок.
   Проверены 15/30/60/144 FPS, оба направления, несколько ростов/дистанций, границы,
   короткий путь, отмена на разных фазах, тихий режим и отсутствие инициативы
   в блокирующих контекстах. Нулевая ошибка опорной точки в этой математической
   модели не обещает нулевое скольжение при реальной композиции Windows.
5. `python tests/offline/check_ik.py`: отдельная NumPy/SciPy реализация тех же IK
   формул на реальных REST-трансформациях Hoshi. Конечные углы, достижимость,
   высота опорной стопы и направление сгиба колена. Не вызовы Skeleton3D.
6. CPU skinning/raster sanity check нескольких поз реальной модели. Файл
   POSE_SANITY_CHECK.png явно помечен как не-Godot. По нему уменьшен постоянный
   присед и введён расчёт высоты таза по досягаемости ног.
7. Проверена целостность архива и всех хешей SHA256SUMS.txt.

Результаты сохранены рядом в JSON. Повторный запуск проверок может обновить отчёты.

## Обязательно проверить на Windows

- Закрыть 0.1.1, запустить TEST_WINDOWS.bat той же версией Godot.
  Требуются итоговая строка HOSHI_TEST_RESULT и failures=0, не просто код 0 от процесса.
- Примерочная: версия 0.2, моргание, кнопки реакций, Пройтись в обе стороны.
- Стоп в начале/середине/конце шага: нет продолжения движения после отмены пути.
- Прозрачный режим: шаги привязаны к движению тела; ноги не уходят в панель задач;
  нет отсечения обуви или руки; меню и колёсико работают; пустые поля не перехватывают
  лишние клики сверх прежней приблизительной маски.
- Во время ходьбы: клик, меню, дремота, перетаскивание, масштаб и переключение режима.
- Перетаскивание в воздух: нет самопроизвольной ходьбы по воздуху. Меню → Вернуть
  к нижнему краю возвращает возможность гулять на выбранном мониторе.
- Монитор с отрицательной координатой, разные DPI, изменение панели/разрешения.
  Нет автоматического пересечения границы текущего монитора. При изменении usable
  area старый путь отменяется.
- Тихая активность: нет самостоятельных прогулок/взмахов; ручная кнопка всё ещё есть.
- Отключённые движения: нет прогулок; моргание и эмоции сохраняются.
- Закрытие/повторный запуск: настройки сохраняются, старый маршрут не возобновляется.

Движковые тесты проверяют реальный импорт/morph channels, позы костей, подъём стопы,
дрейф опорной стопы в world space, достижение цели и оба направления на 30/60 FPS.
Даже успешный headless-результат не проверяет native Windows композицию/прозрачность.

Логи: import.log, session.log, runtime_tests.log. При проблеме со скольжением нужна
короткая запись движения, не только один скриншот. Никакие логи автоматически не
передаются, микрофон/браузер/контент рабочего стола не читаются.
