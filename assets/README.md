# Local avatar

The repository intentionally does not ship a VRM avatar.

For the current development profile, place the local model here:

```text
assets/Hoshi_v1.vrm
```

The current procedural gait, floor sitting and edge poses were calibrated against
the development Hoshi model. Other VRM 1.0 avatars may import successfully but can
need per-avatar calibration.

`assets/*.vrm` is ignored by Git so a local character is not published by accident.
